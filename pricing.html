Free and open source, forever

Cairn is free and open source under the AGPL-3.0 — forever. There are no paid plans, no seat limits, and no license keys. Self-host it for free, on your own infrastructure, with the complete reconciliation engine and every integration.

Get it on GitHub Read the docs

The AGPL-3.0 license is used because Cairn integrates with Snipe-IT, which is also AGPL-3.0. Clone it, build it, and run it however you like.

Frequently asked questions

Is it really free?

Yes — Cairn is open source under the AGPL-3.0, the same license as Snipe-IT, which Cairn integrates with. You can self-host the complete engine at no cost, forever. There are no paid tiers, no seat limits, and no license keys.

How is it funded, and can I get help?

Cairn is a community open-source project. Community support is available through GitHub issues, where you can file bugs, request features, and browse existing discussion. You can also reach out by email at jasvantdosanjh@outlook.com.
