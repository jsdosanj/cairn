Install Cairn

Pick your platform. Signed builds are available to customers in the Cairn dashboard.

Install the signed .pkg, or drop the binary in your PATH:

# Option A — grab the .pkg installer from your Cairn dashboard
# Option B — install the portable binary (use your license token)
curl -fsSL -H "Authorization: Bearer $CAIRN_TOKEN" https://dl.cairn.app/latest/cairn-macos.tar.gz | tar xz
sudo mv cairn /usr/local/bin/
cairn --version

Run the installer, or unzip the portable build:

# PowerShell — download the signed .zip and extract
Invoke-WebRequest `
  -Headers @{ Authorization = "Bearer $Env:CAIRN_TOKEN" } `
  https://dl.cairn.app/latest/cairn-windows-x64.zip `
  -OutFile cairn.zip
Expand-Archive cairn.zip -DestinationPath "$Env:ProgramFiles\Cairn"
cairn --version

Install the .deb on Debian/Ubuntu, or use the tarball anywhere:

# Debian / Ubuntu (.deb)
curl -fsSLO -H "Authorization: Bearer $CAIRN_TOKEN" https://dl.cairn.app/latest/cairn-linux.deb
sudo dpkg -i cairn-linux.deb

# Or the portable tarball
curl -fsSL -H "Authorization: Bearer $CAIRN_TOKEN" https://dl.cairn.app/latest/cairn-linux.tar.gz | tar xz
sudo mv cairn /usr/local/bin/

Prefer Python packaging? Install from the Cairn package index:

pip install cairn --index-url https://$CAIRN_TOKEN@pkg.cairn.app/simple

# then generate a starter config
cairn init > cairn.yaml
